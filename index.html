Política de privacidad

Última actualización: 15 de octubre de 2026

Esta política explica cómo los sistemas de gestión administrados por el responsable de este sitio tratan la información necesaria para gestionar operaciones comerciales y realizar copias de seguridad.

1. Responsable y contacto

Para consultas relacionadas con esta política, podés comunicarte con:

Correo electrónico: goztpy@gmail.com

2. Información que se puede gestionar

Según las funciones habilitadas en cada sistema, se pueden registrar datos comerciales y operativos, como nombres y datos de contacto de clientes y proveedores, materiales, recepciones, ventas, pagos, movimientos de inventario y registros relacionados.

3. Para qué se utiliza la información

La información se utiliza para administrar las operaciones del negocio, consultar historiales, generar registros y reportes, controlar inventarios y realizar copias de seguridad cuando esa función está habilitada.

4. Copias de seguridad y Google Drive

Algunos sistemas pueden ofrecer copias de seguridad mediante Google Drive. Para utilizar esa función, el usuario autorizado puede tener que conectar una cuenta de Google y conceder los permisos que solicite la aplicación.

Los archivos de respaldo se almacenan cifrados cuando la función correspondiente está configurada para ello. El acceso y la conservación de las copias dependen de la configuración del sistema y de los servicios utilizados.

Google Drive está sujeto a las políticas y condiciones de Google. Se recomienda utilizar una cuenta controlada por el propietario del negocio y revisar los permisos concedidos.

5. Compartición de información

No se venden datos personales. La información puede ser procesada por los proveedores tecnológicos necesarios para operar el sistema, alojar sus servicios o realizar respaldos, de acuerdo con las funciones configuradas y los permisos otorgados.

6. Acceso y seguridad

Los sistemas pueden incluir cuentas de usuario y permisos según el rol asignado. Se aplican medidas técnicas y administrativas según la configuración disponible para proteger la información. Ningún sistema puede garantizar seguridad absoluta.

Los usuarios deben mantener sus credenciales privadas y utilizar únicamente los accesos que tengan autorizados.

7. Conservación y eliminación

Los datos se conservan durante el tiempo necesario para las operaciones del negocio y según las decisiones del responsable, las funciones del sistema y las obligaciones aplicables. La eliminación de un registro del sistema no garantiza que desaparezca inmediatamente de todas las copias de seguridad existentes.

8. Servicios de terceros

El alojamiento de los sistemas y las funciones de respaldo pueden depender de proveedores externos, como Render, GitHub y Google. El uso de esos servicios también está sujeto a sus propias políticas.

9. Cambios en esta política

Esta política puede actualizarse para reflejar cambios en los sistemas, sus funciones o las prácticas de tratamiento de información. La versión publicada en esta página será la versión vigente aquí disponible.

10. Consultas

Si tenés consultas sobre esta política o sobre el tratamiento de información dentro de los sistemas, escribí a goztpy@gmail.com.
